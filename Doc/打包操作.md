# SmartFactoryService 打包操作指南

## 项目结构

```
SmartFactoryService/
├── src/main/resources/
│   └── application.yml          # 配置文件（不参与打包）
├── target/                       # 构建输出目录
│   ├── SmartFactoryService-0.0.1-SNAPSHOT.jar   # 可运行 jar
│   └── application.yml           # 外部配置文件（手动复制）
└── pom.xml
```

## 打包命令

在 `SmartFactoryService` 目录下执行：

```powershell
.\mvnw.cmd clean package -DskipTests
```

| 参数 | 说明 |
|------|------|
| `clean` | 清理上次构建产物 |
| `package` | 执行打包 |
| `-DskipTests` | 跳过单元测试（可选，加快构建速度） |

## 配置文件说明

`application.yml` **不参与打包**，作为外部配置使用。配置通过 `pom.xml` 中的资源排除实现：

```xml
<build>
    <resources>
        <resource>
            <directory>src/main/resources</directory>
            <excludes>
                <exclude>application.yml</exclude>
            </excludes>
        </resource>
    </resources>
</build>
```

构建完成后，需手动将 `application.yml` 复制到 `target` 目录，与 jar 包同级：

```powershell
Copy-Item -Path ".\src\main\resources\application.yml" -Destination ".\target\application.yml"
```

## 启动方式

将 `SmartFactoryService-0.0.1-SNAPSHOT.jar` 和 `application.yml` 放在同一目录下。

### 默认启动（自动加载同级 application.yml）

```powershell
java -jar SmartFactoryService-0.0.1-SNAPSHOT.jar
```

### 指定外部配置文件

```powershell
java -jar SmartFactoryService-0.0.1-SNAPSHOT.jar --spring.config.location=file:./application.yml
```

### 指定端口

```powershell
java -jar SmartFactoryService-0.0.1-SNAPSHOT.jar --server.port=9090
```

## Spring Boot 配置加载优先级

1. 命令行参数（`--server.port=9090`）
2. `--spring.config.location` 指定的外部文件
3. jar 包外部的 `application.yml`（与 jar 同级目录）
4. jar 包内部的 `application.yml`（本项目已排除）

## 跨环境部署

只需修改 `application.yml` 中的对应配置项，无需重新打包：

- 数据库地址：`spring.datasource.url`
- MQTT 地址：`spring.mqtt.url`
- 邮件配置：`spring.mail.*`
- DeepSeek API：`deepseek.*`
