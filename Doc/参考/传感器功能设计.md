# 传感器功能设计



##### 一、温湿度模块(温湿度智能监控)

组成：

| 传感器       | sensor | 类型 | 数据形式              | 取值范围                          |
| ------------ | ------ | ---- | --------------------- | --------------------------------- |
| 温湿度传感器 | 25     | 读   | {"temp":38,"humi":33} | 环境温度[-40,125] 环境湿度[0,100] |
| 风扇         | 26     | 写   | {"fan":1}             | 开关状态[0,1]                     |

功能：利用温湿度传感器实时监测生产环境，调整生产环境维持最佳工艺条件。







##### 二、消防模块(危气监测)

组成：

| 传感器     | sensor | 类型 | 数据形式       | 取值范围             |
| ---------- | ------ | ---- | -------------- | -------------------- |
| 电磁水阀   | 35     | 写   | {"water":1}    | 开关状态[0,1]        |
| CO传感器   | 33     | 读   | {"monoxide":5} | 一氧化碳浓度[0,4096] |
| 烟雾传感器 | 31     | 读   | {"smoke":20}   | 烟雾浓度[0,4096]     |
| 声光报警   | 22     | 写   | {"alarm":0}    | 开关状态[0,1]        |

功能：通过烟雾，CO传感器进行监测预警，提高工厂生产安全性





##### 三、小车模块(AGV避障系统)

组成：

| 传感器         | sensor | 类型 | 数据形式          | 取值范围        |
| -------------- | ------ | ---- | ----------------- | --------------- |
| 超声波测距模块 | 40     | 读   | {"ultrasonic":17} | 测量距离[4,300] |
| 声光报警       | 22     | 写   | {"alarm":0}       | 开关状态[0,1]   |

功能：使用超声波传感器为自动导引车（AGV）提供避障解决方案，增强物料运输的安全性与效率。
