## Agent 智能检测功能设计

### 一、功能概述

通过 LLM（DeepSeek V4Pro）对一定时间窗口内**全部传感器**的时序数据进行批量分析，一次性同时完成**预测性维护**和**异常检测**，生成综合诊断报告。

| 维度 | 说明 |
|------|------|
| **分析模式** | 批量分析：每次拉取时间窗口内的全部传感器数据，作为上下文提交给 LLM |
| **检测范围** | 预测性维护 + 异常检测，两者在同一次调用中完成 |
| **技术方案** | langchain4j + DeepSeek V4Pro（OpenAI 兼容 API），无需额外训练模型 |
| **结果存储** | `agent_detection_result` 表（详见 [Agent检测数据库设计](../数据库设计/Agent检测数据库设计.md)） |

---

### 二、功能详解

#### 1. 预测性维护 (Predictive Maintenance)

| 维度 | 说明 |
|------|------|
| **功能描述** | 将传感器时序数据提交给 LLM，由 LLM 分析数值变化趋势，预测未来是否可能跨越危险阈值，给出风险等级和预估剩余安全时间 |
| **传统做法** | 固定阈值判断 `if value > maxTh → alert`，只能在越过阈值后告警 |
| **AI 优势** | **从事后告警变为事前预测**。LLM 能理解数值的上升加速度、周期性波动等隐含趋势，提前预警 |
| **实现方式** | 将传感器配置（含阈值）和近期记录作为 Prompt 上下文，让 LLM 推理趋势并输出结构化结论 |

#### 2. 智能异常检测 (Anomaly Detection)

| 维度 | 说明 |
|------|------|
| **功能描述** | LLM 分析传感器数值的波动模式，检测"数值在阈值内但模式异常"的场景（如频率突变、缓慢漂移、周期性紊乱等） |
| **传统做法** | 固定阈值只能回答"值是否在范围内"，无法感知模式层面的异常 |
| **AI 优势** | **阈值盲区全覆盖**。例如温度始终在安全范围内，但波动频率突然从每小时±1°变成每分钟±3°，传统阈值无法发现，LLM 可以识别 |
| **实现方式** | 将传感器时序数据提交给 LLM，分析其波动规律是否一致，检测异常模式 |

---

### 三、报告输出规则

LLM 单次调用同时执行两项分析，按以下规则输出 `result_report`：

| 分析结果 | 报告格式 |
|----------|----------|
| 预测 + 异常均正常 | 报告以"正常"为主，简要覆盖两方面结论 |
| 仅一方异常 | 异常方**重点详述**（问题、原因、建议），正常方简要带过 |
| 两者均异常 | 两部分均**重点详述** |
| LLM 调用失败 | `status = FAILED`，`result_report` 记录失败原因 |

当存在任意异常时，业务层可将 `is_notified` 置为 1 触发通知。

---

### 四、执行流程

```
定时触发（如每 5 分钟一次）
    │
    ├── 1. 查询 edubox_sensor_config（获取所有传感器的阈值配置）
    ├── 2. 查询 edubox_sensor_record（获取 data_start_time ~ data_end_time 范围内全部记录）
    ├── 3. 组装 Prompt（传感器配置 + 时序数据）
    ├── 4. 调用 DeepSeek LLM 进行分析
    │       │
    │       ├── 成功 → status=SUCCESS, 写入 result_report, 有异常则 is_notified=1
    │       └── 失败 → status=FAILED, result_report 记录错误信息
    │
    └── 5. 插入 agent_detection_result 表
```

### 五、与现有系统集成点

| 模块 | 集成方式 |
|------|----------|
| `SensorDataPusher` 定时任务 | 新增一个定时任务，定期触发 Agent 分析 |
| `SensorRecordService` | 调用 `pageList` 获取指定时间窗口的传感器记录 |
| `SensorConfigService` | 调用 `pageList` 获取所有传感器的阈值配置 |
| `AIAgentService` | 调用 `chatWithSystem()` 提交 Prompt 进行分析 |
| `agent_detection_result` 表 | 持久化每次分析的结果和状态 |
