## GET 获取设备列表

GET /api/device/getDeviceList

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|id|query|integer| 否 |设备ID|none|
|sn|query|string| 否 |设备SN|none|
|type|query|string| 否 |设备类型|none|
|state|query|integer| 否 |设备状态|none|
|pageNum|query|integer| 否 |页码|默认 1|
|pageSize|query|integer| 否 |每页条数|默认 10|
|sort|query|integer| 否 |排序|none|
|Authorization|header|string| 否 ||none|

}
