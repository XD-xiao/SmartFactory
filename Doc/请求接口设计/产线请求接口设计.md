## GET 获取产线运行状态列表

GET /api/device/getPlcList

分页查询PLC产线设备运行状态列表，支持按设备SN和序号筛选。

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|sn|query|string| 否 |设备SN|none|
|seqNo|query|integer| 否 |序号|设备序号|
|pageNum|query|integer| 否 |页码|默认 1|
|pageSize|query|integer| 否 |每页条数|默认 10|
|Authorization|header|string| 否 ||none|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "string",
  "data": {
    "total": 0,
    "list": [
      {
        "id": 0,
        "sn": "string",
        "seqNo": 0,
        "action": 0,
        "workBeginTime": "string",
        "workEndTime": "string",
        "workTime": 0
      }
    ]
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|
|»» total|integer|true|none||none|
|»» list|[object]|true|none||none|
|»»» id|integer|true|none||ID 编号|
|»»» sn|string|true|none||设备SN|
|»»» seqNo|integer|true|none||设备序号|
|»»» action|integer|true|none||动作指令|
|»»» workBeginTime|string|true|none||工作开始时间|
|»»» workEndTime|string|true|none||工作结束时间|
|»»» workTime|number|true|none||工作时长|

## POST 产线设备控制

POST /api/device/controlPlc

向PLC设备发送控制指令，控制指定设备执行指定动作。

> Body 请求参数

```json
{
  "sn": "string",
  "index": 0,
  "action": 0
}
```

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|Authorization|header|string| 否 ||none|
|body|body|object| 是 ||none|
|» sn|body|string| 是 |设备SN|目标PLC设备SN|
|» index|body|integer| 是 |设备序号|产线设备索引编号|
|» action|body|integer| 是 |控制动作|动作指令码|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "string",
  "data": null
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|null|true|none||none|

# 前端调用说明

前端 `DeviceApi.js` 中对应的调用函数：

| 接口 | 前端函数 | 请求方式 |
|---|---|---|
| GET /api/device/getPlcList | getPlcListService(sn, seqNo, pageNum, pageSize) | GET(Query) |
| POST /api/device/controlPlc | controlPlcService(data) | POST(Body: {sn, index, action}) |
