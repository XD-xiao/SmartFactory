# 试验箱模块/传感器配置接口

## GET 获取单条传感器配置

GET /api/eduBox/getSensorConfig

根据传感器配置ID获取单条传感器配置信息。

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|id|query|integer| 是 |配置ID|传感器配置主键ID|
|Authorization|header|string| 否 ||none|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "string",
  "data": {
    "id": 0,
    "sn": "string",
    "sceneType": 0,
    "sensor": 0,
    "config": {},
    "createTime": "string",
    "updateTime": "string"
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|
|»» id|integer|true|none||配置ID|
|»» sn|string|true|none||设备SN|
|»» sceneType|integer|true|none||场景类型|
|»» sensor|integer|true|none||传感器类型编号|
|»» config|object|true|none||配置内容(JSON)|
|»» createTime|string|true|none||创建时间|
|»» updateTime|string|true|none||更新时间|

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|pageNum|query|integer| 否 |页码|默认 1|
|pageSize|query|integer| 否 |每页条数|默认 10|
|sn|query|string| 否 |设备SN|none|
|sceneType|query|integer| 否 |场景类型|none|
|sensor|query|integer| 否 |传感器类型编号|如 25 表示温湿度传感器|
|Authorization|header|string| 否 ||none|

> 200 Response

```json

  "message": "string",
  "data": {
    "total": 0,

        "config": {},
        "createTime": "string",

    ]
  }
}
```

# 前端调用说明

前端 `DeviceApi.js` 中对应的调用函数：

| 接口 | 前端函数 | 请求方式 |
|---|---|---|
| GET /api/eduBox/getSensorConfig | getSensorConfigByIdService(id) | GET(Query: id) |
| GET /api/eduBox/getSensorConfigList | getSensorConfigListService(pageNum, pageSize, sn, sceneType, sensor) | GET(Query) |
| POST /api/eduBox/addSensorConfig | addSensorConfigService(data) | POST(Body) |
| PUT /api/eduBox/updateSensorConfig | updateSensorConfigService(data) | PUT(Body) |
| DELETE /api/eduBox/deleteSensorConfig | deleteSensorConfigService(id) | DELETE(Query: id) |
| GET /api/eduBox/getSensorRecordList | getSensorRecordListService(params) | GET(Query) |
